# Claude 学習マニュアル 配布物

Claude のデスクトップアプリ(Code 機能)で使う、**手順書(スキル)** をまとめて置いてあります。受講者向けです。

## 入っているもの

| 名前 | 何をするもの | 使うレッスン |
|---|---|---|
| `skills/planning-website-mock` | HP を作る前に、参考サイトを選び、決めることを確認し、完成イメージ(モック)を作る | レッスン3・4 |
| `skills/automating-note-articles` | note の記事を、編集長・ライター・レビュアーの3人の AI チームで、審査に通るまで作る。公開は人が行う | レッスン5 |
| `skills/automating-sns-posts` | 記事の1節を材料に、Instagram のカルーセル(画像とキャプション)を作り、品質チェックを通ったものを保存して止まる。投稿は人が行う | レッスン6 |

**必要になったレッスンで、その手順書を入れます。** 先に全部入れなくて構いません。ほかのレッスンで使うものは、そのレッスンで必要になったときに足します。

## 入れ方

[01_スキルを入れる.md](01_スキルを入れる.md) を開いてください。10分ほどで終わります。

## このリポジトリについて

- 手順書は文章のファイルです。開けば全部読めて、書き換えられます。
- パスワードや個人情報は入っていません。
- 内容は、ベータ版として、使いながら直していきます。
