# automating-note-articles（note 記事を自動で作るスキル）

会社のオウンドメディア（note）の記事を、AI の3人チーム（編集長・ライター・レビュアー）が **審査に合格するまで自動で** 作るスキルです。note への貼り付けだけは人の手で行います。

```
① 置き場所 → ② 保存先を決める → ③ ひな形をコピー → ④ 通知先を決めて試し送り
→ 記事に必要な情報を集める → ⑤ 設定を埋める → ⑥ キーを用意 → ⑦ DB を作る
→ ⑧ 手動で1周 → ⑨ 定期実行（聞いてから）
```

## 置き方

1. このフォルダ（`automating-note-articles`）を、次の場所に丸ごと置く
   - Windows: `C:\Users\<あなたのユーザー名>\.claude\skills\automating-note-articles\`
   - Mac: `~/.claude/skills/automating-note-articles/`
   - `skills` フォルダが無ければ作る。`.claude` は隠しフォルダなので、エクスプローラーの「表示 → 隠しファイル」をオンにすると見える
2. Claude Code を起動し直す

## 使い方

Claude Code に「note 記事を自動で作りたい」「オウンドメディアの記事を自動生成したい」と話しかけると起動します。起動すると、最初に流れを見せて「1つずつ一緒に確認していきますか？（YES/NO）」と聞くので、それが出れば正しく動いています。

## 最初に用意してもらう情報

記事は、**あなたがくれた情報だけ**で書きます。足りない情報は推測で埋めず、空欄のまま止まります。始める前に、次を依頼主（会社の担当者）から集めてください。くわしい表は `SKILL.md` の「記事に必要な情報の集め先」にあります。

| 情報 | もらう先 |
|---|---|
| 読者・記事の目的・トーン | 依頼主へのヒアリング |
| 会社・商品の事実（出所つき） | 会社の公式サイト・パンフレット・商品ページ・担当者 |
| 商品名と販売ページの URL | 担当者 |
| 言えないこと（広告の規制など） | 依頼主の社内ルール、業界団体・官公庁のガイドライン |
| 現場の言葉（インタビュー風のときだけ） | 担当者への取材 |

## 必要なもの

| もの | 使う段 | 費用 |
|---|---|---|
| Claude Code | 全体 | ― |
| Python | スクリプトの実行 | 無料 |
| PowerShell | 自動実行（`run-agent.ps1`）。Windows 前提の作り | 無料 |
| Cloudflare のアカウント | 記事の保存（D1） | 無料枠（Supabase を選ぶ場合は書き直しが要る） |
| 通知先（Discord・Slack・Gmail など） | 結果の通知 | 無料。Chatwork は有料プラン、LINE は公式アカウントが要る |
| Jina のキー | 出典集めの検索 | 無料枠。無くてもページは読める |
| Gemini のキー | 画像の自動生成 | 無料枠では使えない場合がある。使わなければ、画像の指示文だけ作って自分で画像にする（無料） |

## フォルダの中身

```
automating-note-articles/
├── README.md                … この説明（Claude は読まない）
├── SKILL.md                 … スキル本体（流れとルール）
└── template/                … ひな形（案件へコピーして使う）
    ├── README.md            … 仕組み・使い方の説明書
    ├── media.config.json    … 案件ごとの設定（（）を全部埋める）
    ├── facts/               … 確かめた事実・取材メモ
    ├── d1/                  … 記事の保存先 DB の表
    ├── scripts/             … 記事づくりのスクリプト
    └── .claude/             … 編集長・ライター・レビュアーの手順書
```

## 大事な約束

- 最初に流れを見せて「1つずつ確認しますか？（YES/NO）」と聞きます。この進め方を自分の CLAUDE.md に入れるかも1度だけ聞きます（OK のときだけ書き足します）
- 会社の発信として外に出る文章なので、**本人が確かめた事実だけ**を使います。仮の素材や推測は入れません
- 通知先を決めて「届いた」と確かめるまで、設定には進みません（自動実行の結果に気づけないまま動かさないため）
- note への貼り付けは人の手で行います
- 通知先のキーやパスワードは、チャットに貼らず、自分で `.env.local` に書いてください
- 食品・健康など、広告で言えない表現がある業種では、`media.config.json` の `forbidden` に必ず書いてください
