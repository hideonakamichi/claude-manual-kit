# 確かめた事実（会社・商品）

記事で **会社と商品について書いてよいのは、このファイルにあることだけ**。
ここに無いこと（製法・歴史・こだわり・価格・内容量・受賞歴など）は、確かめられるまで書かない。
増やすときは、人が確かめてから「出所」と一緒に書き足す。HP キットがあれば、素材リストの ✅ だけを写す（🟨 仮は写さない）。
