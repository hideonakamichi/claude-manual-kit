# Claude Design を初めて使う人への案内

Step 5 に入る前に「Claude Design を使ったことがありますか？」と聞く。**使ったことがない人にだけ**この案内を使う。慣れている人には出さない。

## 進め方の決まり

- **1回の返信で1ステップだけ。** 本人の「できた」を待ってから次へ進む（Claude は画面を見られないため、つまずいた場所が分からなくなる）
- 画面のボタン名は、本人が見ている表示に合わせて言い直してもらう。こちらの言い方と違っても止まらない
- 開けない・見つからないときは、無理に進めず「フォールバック」へ

## ステップ

| # | 本人にお願いすること | できたかの目安 |
|---|---|---|
| 1 | Claude から渡されたリンクを、**ふだん Claude を使っているアカウント**でログインしたブラウザで開く | キャンバス（白い作業台）に、PC版とスマホ版の下書きが並んで見える |
| 2 | キャンバスを動かしてみる。ドラッグで移動、拡大・縮小で全体と細部を見る | 下書きの上から下まで見られる |
| 3 | 下書きの中の文字をクリックして、1か所だけ書き換えてみる（例: 見出し） | 書き換えた文字が残る |
| 4 | 色や余白を変えたい部分を選び、右側の設定欄（プロパティ）で値を変えてみる | 選んだ部分だけ見た目が変わる |
| 5 | 「Tweaks」を開き、全体に効く設定（差し色など）を切り替えてみる | ページ全体の色が一度に変わる |
| 6 | 気になる点は、自分で直すか、Claude に「ここを直して」と頼むかを選ぶ | どちらで進めるかが決まる |

## 伝えておくこと

- 下書きは**本人だけが見られる状態**で作られる。ほかの人に見せるときは、画面の共有（Share）メニューから共有する。Claude からは共有できない
- 本人が手で直した内容は消えない。Claude が後から直すときは、本人の変更を読み込んでから直す
- 迷ったら、変えたい場所と変えたい内容を言葉で Claude に伝えればよい。全部を自分で操作できなくても進められる

## フォールバック（開けない・使えないとき）

- リンクが開けない: ログインしているアカウントが、下書きを作ったアカウントと同じか確認してもらう
- それでも使えない: アカウントで Claude Design が使えるかを本人に確認してもらう（Claude からは判断できない）
- 使えないと分かったら: 下書きを HTML ファイル（ブラウザで開ける1枚のページ）として渡し、直したい点を Claude にチャットで伝えてもらう形に切り替える
