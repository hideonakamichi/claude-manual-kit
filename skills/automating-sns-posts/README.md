# automating-sns-posts（Instagram のカルーセルを半自動で作るスキル）

自分の文章（note 記事など）の1節を根拠に、Instagram の図解カルーセル（画像3〜6枚）とキャプションを作り、
AI の品質チェックを通ったものを保存して止まるスキルです。**投稿は人が行います。**

```
置き場所 → ひな形をコピー → ネタ元（自分の文章）を置く → brand.yaml を埋める
→ 1本作る（保存して止まる）→ 人が確かめて、自分で投稿する
```

## 置き方

1. このフォルダ（`automating-sns-posts`）を、次の場所に丸ごと置く
   - Windows: `C:\Users\<あなたのユーザー名>\.claude\skills\automating-sns-posts\`
   - Mac: `~/.claude/skills/automating-sns-posts/`
   - `skills` フォルダが無ければ作る。`.claude` は隠しフォルダなので、エクスプローラーの「表示 → 隠しファイル」をオンにすると見える
2. Claude Code を起動し直す

## 使い方

Claude Code に「Instagram の投稿を半自動で作りたい」「カルーセルを作りたい」と話しかけると起動します。
起動すると、最初に流れを見せて「1つずつ一緒に確認していきますか？（YES/NO）」と聞くので、それが出れば正しく動いています。

## 必要なもの

| もの | 使う段 | 費用 |
|---|---|---|
| Claude Code | 全体 | ―（1本ごとに利用枠を使う） |
| Python 3.10 以上 | 画像を描くスクリプト | 無料 |
| Pillow・PyYAML（`pip` で入る） | 画像を描く・設定を読む | 無料 |
| 日本語のゴシック体フォント | 画像の文字 | 無料（Windows・Mac に最初から入っている） |
| 自分の文章（note 記事など） | ネタ元 | ― |
| Instagram のアカウント | 投稿するとき（作るだけなら不要） | 無料 |

アカウントのパスワードや API キーは要りません。

## フォルダの中身

```
automating-sns-posts\
├── README.md          ← このファイル
├── SKILL.md           ← Claude が読む手順
└── template\
    ├── README.md               ← キットの仕組み・つまずき
    ├── CLAUDE.md               ← 共通のルール
    ├── config\                 ← brand.yaml（アカウントの人格）・やり直し回数の上限
    ├── content\sources\        ← ネタ元（自分の文章）を置く
    ├── .claude\                ← 司令塔・ネタ選び・キャプション・評価・描画の手順とスクリプト
    ├── docs\                   ← 見た目の方針・この後の世界
    ├── examples\               ← カルーセルの構成の作例
    ├── output\                 ← 生成物（自動でできる）
    └── logs\                   ← 作成記録（自動でできる）
```

## 大事な約束

- **投稿は人が行う。** このスキルは Instagram へ投稿しない。シェアを押す前に、画像とキャプションを自分の目で読み返す
- **材料にない事実は書かない。** 投稿に書かれる事実は、置いた文章の1節にあることだけ。AI が足した話は品質チェックが不合格にする
- **言えないことは `brand.yaml` に必ず入れる。** 効能・価格・断定など、業界の決まりは自分で確かめて登録する
- **中止でも利用枠を使う。** 品質チェックで中止になる回がある。理由を読んでから、材料か設定を直してもう一度頼む
