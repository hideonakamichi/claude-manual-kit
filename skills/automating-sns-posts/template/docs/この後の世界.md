# この後の世界：すべてが自動で回る仕組み

このキットは、**作るところまで**を扱います。出すのは、あなたの手です。

この先には、**作る・確かめる・出す・知らせる・次の回を始める、までが人の手なしで回る世界**があります。ここでは、その世界がどうなっているかを見せます。**今日やる必要はありません。** 手を動かした人だけが、「やってみたい」と思える場所です。

## 全体の姿

```text
曜日と時刻が来る
  ↓
ネタを選ぶ → 作る → AI が品質チェック
  ↓ 合格                    ↓ 不合格が続く
Instagram に投稿する         投稿せずに止まり、理由を知らせる
  ↓
記録して、結果を知らせる(Discord など)
  ↓
次の回まで待つ
```

レッスン6までに、あなたは上の図の**2段目(ネタを選ぶ → 作る → 品質チェック)**を、自分の手で動かしました。残りは、**「出す」「知らせる」「時刻で起こす」**の3つです。

## 足りない3つの部品

| 部品 | 何をするか | 用意するもの |
|---|---|---|
| 出す | 完成した画像を、Instagram に自動で投稿する | Instagram のプロアカウント、Meta の開発者アプリ、画像の置き場所(Cloudflare R2) |
| 知らせる | 成功も失敗も、あなたに届ける | Discord などの通知先(レッスン5で選んだものと同じ考え方) |
| 時刻で起こす | 決めた曜日・時刻に、作る処理を始める | Windows のタスク スケジューラ |

**この3つが全部そろって初めて、「自動」になります。** どれか1つが欠けると、止まったことに誰も気づけません。

### 「出す」が、いちばんの山です

Instagram の API(アプリから Instagram を操作するための窓口)を使うには、次の手順が要ります。

1. Instagram を**プロアカウント**にする
2. Meta for Developers で**アプリを作る**
3. 「Instagram 業務用ログイン」で、**長期のアクセストークン**(合鍵)を取る
4. 画像を**公開 URL に置く場所**を用意する(Instagram の API は、公開 URL の画像しか受け取らないため)

アクセストークンは、**約60日で切れます。** 切れる前に更新する仕組みも、一緒に要ります。

## 知っておいてほしい現実

このキットの元になった運用では、次のことが分かっています。

- **品質チェックで、かなりの回が中止になります。** あるアカウントの実績では、カルーセルは6回中5回が投稿に至り、リールは7回中2回でした。中止は失敗ではなく、「変な投稿を出さない」ための安全装置です
- **中止でも、費用はかかります。** Claude の利用枠は、成功した回と同じだけ減ります
- **最初の数回は、必ず自分の目で確かめます。** 無人で公開される仕組みは、出てしまったものを取り戻せません

> **「全部自動」は、ゴールではなく選択肢です。** 週に1本、自分で確かめて出すほうが、合う人もいます。

## リールも、同じ仕組みで作れます

カルーセルの次に、**10〜20秒の縦型動画(リール)**があります。映像は動画生成の AI、ナレーションは音声合成、BGM は手持ちの音源で作ります。動画ソフト(ffmpeg)や、有料のサービスが要るので、**カルーセルが安定してから**で十分です。

## 自分で試すなら、この順番で

一気に作らず、**1段ずつ、動くのを確かめてから**次へ進みます。

1. **作る**(今日のレッスン): 出す前に、毎回自分の目で確かめる。これを数回
2. **知らせる**: 作り終わったときに、通知が届くようにする
3. **出す**: 投稿だけを自動にする。**最初の数回は、実行する前に自分の OK を挟む**
4. **時刻で起こす**: 週1回から始める。毎日にはしない
5. **ほかの場所に配る**: 同じ内容を、Threads や X にも出す(今は、作る手順の設計だけがあります)

進め方は、レッスン5・6と同じです。**Claude に「やりたいこと」を日本語で頼み、1つずつ、何が起きるかを見せてもらい、確かめてから進めます。** 分からない言葉は、そのまま Claude に聞いてください。

## 守ること

- **取り消せないもの(公開・削除・支払い)の前に、必ず人が見る。** 自動にするのは、確かめ終わったことだけ
- **止まったことに気づける仕組みを、先に作る。** 通知が届かない自動化は、静かに壊れ続けます
- **少ない頻度で始める。** 週1回で、数週間うまく回ってから増やす
- **キーやトークンは、チャットに貼らない。** 自分で、決まったファイルに書く
- **投稿の責任は、動かした人にあります。** 規約や、アカウントへの影響は、自分で確かめます

## 最後に

今日までに、あなたは**HP を公開し、note の記事を作り、Instagram の投稿を作りました。** どれも、日本語で頼み、出てきたものを自分の目で確かめて、決めたものです。

この先は、**確かめる役を、少しずつ仕組みに渡していく**道のりです。ただし、渡す前に、**自分の手で十分に回したことがあるか**が、いちばん大事です。そこまで来たあなたなら、続きを自分で作れます。

次の一歩は、あなたが決めてください。
