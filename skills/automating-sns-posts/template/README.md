# Instagram カルーセル作成キット（人が投稿する版）

自分で書いた文章を置いておくと、その1節を根拠にして、図解カルーセル（4:5・3〜6枚）と
キャプションを作り、AI の品質チェックを通ったものを `output/` に保存して**止まる**キットです。
**Instagram への投稿は、あなたが画像とキャプションを確かめてから、自分の手で行います。**

発信の中身を決めるのは `config/brand.yaml`（誰に・何を・どんなトーンで）と、
`content/sources/` に置く自分の文章だけです。スクリプトやエージェントの定義は触らずに、
別のジャンルのアカウントへそのまま使えます。

| 作るもの | 中身 |
|---|---|
| カルーセル | 図解スライド3〜6枚（4:5）。文字は Pillow で直接描くので誤字が出ない |
| キャプション | 本文（5〜8文）とハッシュタグ10〜15個 |
| 確認用の記録 | どの節を選んだか、品質チェックの合否と理由（`チェック結果.md`） |

---

## 始める前に知っておいてほしいこと

**品質チェックで中止になる回があります。** 生成物は毎回、評価専用のエージェント（evaluator）が
合否を判定します。不合格なら該当箇所だけ作り直し、2回で通らなければ中止して、理由を画面に出して止まります。
「変な投稿を出すくらいなら出さない」側に倒した設計です。

**1本ごとに、Claude の利用枠を使います。中止した回にも同じだけかかります。** 最初は少ない本数で試してください。

**投稿の責任は、投稿する人にあります。** 品質チェックは完全ではありません。
画像とキャプションは、必ず自分の目で読んでから出してください。

---

## 必要なもの

- Windows または Mac
- [Claude Code](https://claude.com/claude-code)（デスクトップアプリの Code でよい）
- Python 3.10 以上（`python --version` で確かめる）
- 日本語のゴシック体フォント（Windows は BIZ UD ゴシック・游ゴシック・メイリオ、Mac はヒラギノ角ゴシック。通常は最初から入っています）

アカウントのパスワードや API キーは**要りません**。Instagram に自動でつなぐ設定はありません。

---

## セットアップ

### 1. 道具を入れる

このフォルダで、次を1回だけ実行します（Claude に「次のコマンドを実行して」と頼んでもかまいません）。

```bash
python -m pip install pillow pyyaml
```

分けて管理したいときは、先に `python -m venv .venv` を作り、`.venv` を有効にしてから入れます。

### 2. アカウントの設定と、ネタ元の文章を用意する

このフォルダで Claude Code を開き、次のように頼みます。

```
brand-setup スキルで設定して。発信したいのは〇〇で、売りたいのは△△
```

対話で質問に答えていくと、`config/brand.yaml` が埋まり、投稿の根拠になる文章
（`content/sources/*.md`）も用意できます。すでに文章があるときは、`content/sources/` に置きます。
**1節（`## 見出し`）は200字以上** にしてください。

`config/brand.yaml` に雛形のままの値（`（…）` や `@your_account`）が1つでも残っていると、作る段階で止まります。
設定が済んだかは次で確認できます。

```bash
python .claude/skills/shared/scripts/check_brand.py
```

## 1本作る

このフォルダで Claude Code に、次のように頼みます。

```
.claude/orchestrators/banner-manual-orchestrator.md に従って、カルーセルを1本作って。
投稿はしないで、output に保存して止まって。
```

10〜20分かかります。Claude が、ネタ選び → 構成 → 描画 → 品質チェック → キャプション → 品質チェック → 保存、
の順に進めます。終わると、保存先のフォルダ名と、選んだ節・チェック結果が画面に出ます。

### 出力の見方

`output/<日付>_<テーマ>/` に、次が残ります。

| ファイル | 中身 |
|---|---|
| `slide_<n>_<role>_<時刻>.png` | 投稿用の画像（4:5、1080x1350）。番号順に使う |
| `caption.txt` | キャプションとハッシュタグ |
| `チェック結果.md` | どの節を選んだか、評価の合否と理由 |
| `carousel_spec.json` | 構成の設計書（画像の文字の元） |

エクスプローラーでフォルダを開き、**画像とキャプションを自分の目で確かめて**から投稿します。
ずれていたら `config/brand.yaml` を直して、もう一度作ります。

---

## ネタ元の文章について

投稿は、`content/sources/` に置いた Markdown の1節（`## 見出し` の単位）の紹介として作られます。
画面・キャプションに書かれる事実は、その節に書いてあることだけです。AI が自分の知識で話を
足した場合は evaluator が不合格にします。

ここに置く文章の質が、そのまま投稿の質になります。置くものは、ブログや note の記事、
よく聞かれる質問とその答え、商品やサービスの説明など、自分が内容に責任を持てる文章です。
書式と注意は `content/sources/README.md` にあります。

同じ節は、ほかに選べる節があるかぎり14日間は再登場しません。作る予定の本数の2倍以上の節があると、
繰り返しを避けられます。

効果効能・価格・まだ決まっていない制度など、書き方に縛りのある話題は、`brand.yaml` の
`content_sources.cautions` に語句と注意書きを登録しておきます。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「描画用の日本語フォントが見つかりません」 | 日本語のゴシック体が入っていない。画面に出た名前のフォントを入れる |
| 「ネタの索引がありません」で中止される | `content/sources/` に文章が無いか、どの節も200字未満。`python .claude/skills/shared/scripts/build_article_index.py --check` で件数を確認する |
| 作る前に「設定が足りない」と止まる | `brand.yaml` に雛形の文字が残っている。`check_brand.py` が教えてくれる |
| 何度も不合格になる | ネタ元が薄い、またはトーンの設定と文章が噛み合っていない。節を厚くする、`brand.yaml` を見直す |
| 表紙や最後の枚に、途中で切れた記事名が出る | タイトルが13字を超えている。front matter の `short_title` か `brand.yaml` の `content_sources.short_titles` に短い名前を登録する |
| 文字が小さい・はみ出す | 1枚の文字が多い。Claude に「1枚の文字を減らして」と頼む |

## ディレクトリ構成

```
config/brand.yaml        アカウントの人格（読者・トーン・オファー・色・ネタ元の設定）
config/loop-limits.yaml  やり直し回数の上限（緩めると、失敗時に利用枠だけが減る）
content/sources/         ネタ元（自分の文章を Markdown で置く）
content/articles/        ネタ元から自動で切り出された、節ごとの根拠テキスト（手で編集しない）
content/themes.md        いまある紹介ネタの一覧（自動生成。眺める用）
.claude/orchestrators/   司令塔への指示書（カルーセルを作って保存して止まる）
.claude/agents/          ネタ選定・キャプション・評価の各エージェント
.claude/skills/          カルーセル描画・初期設定の手順とスクリプト
docs/DESIGN.md           見た目の方針（余白・3色以内・1枚1メッセージ）
docs/この後の世界.md      自動で投稿する世界の紹介（卒業後に読む）
examples/                カルーセルの構成の作例
output/                  生成物（1本ごとにフォルダが残る）
logs/                    作成記録（created.jsonl）
CLAUDE.md                すべての手順に共通のルール
```

---

## 含まれていないもの

- **ネタ元の文章**: 書式の見本（`content/sources/_sample.md`）だけが入っています。見本は投稿には使われません
- **Instagram への自動投稿・リール・定期実行**: このキットには入っていません。`docs/この後の世界.md` を読んでください
